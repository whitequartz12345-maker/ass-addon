# ass-addon (Meteor Client)

Modules: SusChunkFinder, SusChunk V2, Star ChunkFinder, Ass Freecam, Deep Block Noti, Base ESP, Ass Tool.

Credits / note: Krypton's "sus chunk" lives in the CHUKL addon. The modules here are
independent, original implementations of the same general idea, not copies of that code.

Build: push to GitHub, run the "Build" action, download the jar from the run's artifacts.
Install: drop the jar in `.minecraft/mods` next to Meteor Client.
